# DC Variable Voltage Source

**Analog-circuit design project for a controllable DC output supply, documented through simulation and circuit schematics.**

The project focuses on the basic design of a variable DC power source and the role of rectification, regulation and controlled output voltage in practical power-supply circuits.

## Project Scope

- Variable DC output-supply design.
- Circuit-level simulation and schematic verification.
- Practical study of regulated DC power delivery.
- Documentation of the complete circuit configuration.
